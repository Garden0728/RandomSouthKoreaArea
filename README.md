## 📖 Description
- 오프라인에서 직접 지도 종이에 던져 랜덤으로 뽑는 방식을 온라인 서비스로 구현했습니다.
- 매번 어디갈지 고민하지 말고 친구 혹은 지인과 함께 랜덤으로 여행지를 뽑고 바로 떠나 보세요!
- 계획 없이 여행을 즐기는 분들께 추천합니다.

---

## ✨ Main Feature
- 랜덤 국내 여행 지역 추천
   - 버튼 클릭 한 번으로 국내 여행지를 무작위로 추천합니다.
   - 선정된 지역의 지번 주소를 즉시 확인할 수 있습니다.
- 지도 기반 여행지 시각화 
    - 추천된 여행지를 지도 위에 마커와 행정구역 경계로 확인할 수 있습니다.
